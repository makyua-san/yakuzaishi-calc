# 小児科用量チェッカー

薬剤師向けの小児科処方支援ツールです。体重・年齢に基づく推奨用量の算出と、処方量との比較判定を行います。

## 機能

- **薬剤選択**: 6種類の小児科頻用薬から選択
  - アモキシシリン（抗菌薬）
  - アセトアミノフェン（解熱鎮痛薬）
  - クラリスロマイシン（抗菌薬）
  - セフジトレンピボキシル（抗菌薬）
  - カルボシステイン（去痰薬）
  - ツロブテロール（気管支拡張薬）

- **推奨用量計算**: 年齢・体重から添付文書に基づく推奨用量を自動算出

- **処方量判定**: 入力された処方量と推奨量を比較し、適正/注意/要確認を判定

- **計算過程の可視化**: 計算ステップを詳細に表示し、根拠を明確化

- **履歴機能**: 最近使った薬剤をローカルストレージに保存

## 使い方

1. **薬剤選択**: 一覧から薬剤を選択、または検索
2. **患者情報入力**: 年齢（スライダー）と体重（スライダー）を設定
3. **処方情報入力**（任意）: 1回量と1日回数を入力
4. **結果確認**: 推奨用量と判定結果を確認

## 注意事項

本ツールは検算・根拠提示の支援ツールです。最終判断は薬剤師が添付文書・施設基準・患者状態を確認の上で行ってください。
